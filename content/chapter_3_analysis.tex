First, a genome-wide assessment of motif enrichment near TSSs is generated by scoring occurrence of \num{10000} motif PWMs aggregated from various databases using ClusterBuster\sjcitep[]{frith2003cluster}, generating for each PWM a ranking of the genes it may regulate. A set of genes, derived from e.g. differential gene expression or co-expression data, can then be checked for overrepresentation in these PWM-gene rankings using an area under the rank curve approach. \section{Single-cell data pre-processing}
% The newly available human genome, in conjunction with large amounts of data generated by microarray and sequencing-based quantitative assays, necessitated the development of new bioinformatics tools.
Once data is sequenced, and raw \verb|.fastq| data is available, the first step in data analysis is alignment to a reference genome. A number of algorithms exist for this task, and the optimal choice depends on several factors. Short-read aligners such as \verb|bowtie2| are optimized for reads < \SI{200}{\bp}, while long-read aligners like \verb|minimap2| are better at handling reads > \SI{1000}{\bp}. The type of sequencing technology used also plays a role: sequencing by synthesis (Illumina) generates more indels due to incorporation errors, and these need to be explicitly corrected for by \verb|bwa-mem|, whereas \verb|minimap2| is better suited for handling the higher single-base error rates found in Nanopore/PacBio reads.

Whereas genomic reads, such as generated by ChIP-seq, can be directly aligned to the genome, mRNA transcripts overlap discontinuously with the genome due to splicing, and are thus more challenging to align. Aligning short-read RNA-seq data to the genome requires splice site annotations, which required expressed sequence tags (ESTs) or full-length cDNA sequencing to generate. TopHat ended the need for ESTs by introducing computational splice site identification\sjcitep[.]{trapnell2009tophat} The algorithm identifies exons by looking for splice site motifs near the flanks of the reads that only partially map ("initially unmapped") to the reference genome with \verb|bowtie|. Multiple reads are then aggregated to statistically validate a splice site. The resulting read alignments can then be passed to Cufflinks\sjcitep[,]{trapnellTranscriptAssemblyQuantification2010} which assembles them into possible transcript isoforms and can provide a statistical estimate of their relative quantities without long-read cDNA sequencing data.

% Newer \verb|HISAT2|\sjcitep[]{pertea2016transcript} are used to handle spliced reads.

Like many classes of algorithms, a trade-off between memory and compute can also be made, for example \verb|STAR|\sjcitep[]{dobin2013star} requires large amounts of memory due to its use of an uncompressed genome index, but is faster, while \verb|HISAT2| is more memory-efficient, but takes longer.

% STAR's high mapping speed and accuracy were crucial for analyzing the large ENCODE transcriptome (Djebali et al., 2012) dataset (>80 billion Illumina reads)

The diversity in sequencing technologies and alignment algorithms led to the use of several independent alignment formats, each tied to specific sequencing technologies or alignment algorithms. Analyses on different datasets (e.g. variant calling, genotype analysis) required cross parsing or conversion. The introduction of the sequence alignment map (\verb|SAM|) format as part of the 1000 Genomes Project in 2009\sjcitep[,]{liSequenceAlignmentMapFormat2009} provided a unified standard for storing aligned sequencing data which has since become the de facto standard. Each read is stored in a single line containing 11 mandatory fields including: read name, reference name (chromosome or contig), position, mapping quality, the actual sequence, several other alignment quality parameters as well as optional tags.

An indexed binary representation (\verb|BAM|) saves storage space and speed up searching and processing with random access. This also allows users to quickly inspect desired genomic regions using visualisation tools like \verb|igv|\sjcitep[.]{thorvaldsdottirIntegrativeGenomicsViewer2013}. Alignment quality itself is also a useful metric for assessing an experiment, where low genomic or transcriptomic alignment rates are indicative of low quality. When this occurs independently of per-base sequencing quality (i.e. sequencing run issues), either sample quality (degradation, viability) or library preparation (low input DNA, low reverse transcription efficiency, over-amplification or over-fragmentation) are usually at fault. Additionally, metrics such as reads mapped to the mitochondrial genome can indicate sample damage. These cases require optimization searches of better extraction and library prep parameters

After alignment, the next step is to vectorize the data by counting aligned reads in genomic regions. This generates a cell by feature count matrix, unlocking linear algebra (\autoref{tab:feature_count_matrix}). The region sets used for counting differ by assay used. scRNA-seq requires gene sets, whereas for ATAC-seq several strategies exist: ideally, previously validated sample-specific peak regions are used to limit data sparsity, but when these are not available, public data can be used. Particularly, the ENCODE SCREEN regions is a set of \num{926535} human and \num{339815} mouse candidate cis-regulatory elements (cCREs) identified based on ATAC-seq, DNase hypersensitivity, CHiP-seq, histone modifications (H3K4me3, H3K27ac), and CTCF binding aggregated from over \num{9000} efforts\sjcitep[.]{encode2020expanded} These regions represent potential enhancers, promoters, and insulators. The SCREEN regions should be masked with identified problematic regions (repeats, assembly gaps, nuclear-mitochondrial fragments).  Filtering these regions removes false ChIP-seq peaks, improving biological interpretation and ENCODE QC metrics\sjcitep[.]{amemiya2019encode}

Raw count matrices contain all counts in all barcodes sequenced in the dataset. Filtering true cells from background noise barcodes is a dataset-defining step. The barcode-rank plot (also referred to as "knee" or "elbow plot") visualises the distribution of reads across all sequenced barcodes in the sequencing dataset (\autoref{fig:kneeplot}). It is obtained by counting the number of reads per barcode, and ranking each barcode in a log-log figure - similarly in concept to a Zipf or Lorenz curve.

	\centering

	\captionsetup{width=0.85\linewidth}
	\caption[Barcode rank simulation]{The barcode rank plot. In this simulation, 200 million reads are distributed across \num{10000} cells, and the whitelist is \num{800000} barcodes in length. The ceiling for mean number of reads per barcode is thus 200M reads/10k cell = 20k reads/cell (perfect signal), with a floor of 200M reads/800k barcodes = 250 reads/barcode (perfect noise).}
	\label{fig:kneeplot}
\end{figure}

In the "ideal signal" case, all reads are evenly distributed across a small number of barcodes that matches the number of input cells (e.g. \num{10000} in the figure). This means that there are no quality differences between real cells, and there are no barcodes with low read counts. The opposite scenario ("ideal noise") has an even distribution of all reads across \textit{all} barcodes, and we cannot distinguish true cell barcodes from noise barcodes. Real datasets fall between these two extremes. A high quality dataset exhibits a clear cut-off, where the number of reads per barcode sharply drops off in the transition between real cells and background noise. A dataset of lower quality will exhibit a more gradual transition between real cells and background noise. Based on this simple plot, we can estimate at a glance the rough quality characteristics of any single-cell dataset:

\begin{itemize}[noitemsep]
	\item The number of cells captured in the dataset is given by the barcode rank where true cells are separated from background noise ("knee"). If the dataset is sequenced to near-saturation, the total number of barcodes can even exceed the whitelist, as sequencing/PCR/synthesis errors introduce non-whitelisted species.
	\item The approximate number of reads associated with each true cell can be estimated from the y-axis.
	\item Overall data quality can be estimated by comparing the area under real cells and area under noise, or simply the "sharpness" of the cutoff.
	\item Total noise can be inferred by looking at the number of reads present after the true cell cutoff, taking into account that an equal fraction of noise is also present in the true cells, for example stemming from cross-contamination or bead impurities\sjcitep[.]{lareau2020inference}
\end{itemize}

\section{Single-cell data post-processing}
% [It would actually be better to structure this paragraph as such: "compared to rna-seq data, scrna-seq data has two problems: one it is more non-linear because of the added cell states and two drop-outs additionally make it more difficult to do statistical test. this is solved by...:"]

Conventional bulk RNA-seq analysis tools modeled gene counts using Poissonian (edgeR\sjcitep[]{robinsonEdgeRBioconductorPackage2010}) or Negative Binomial (DESeq\sjcitep[]{andersDifferentialExpressionAnalysis2010}) distributions. Statistical tests can then be used to identify statistically significant differentially expressed genes. Compared to bulk RNA-seq and microarray data, single-cell sequencing data is highly zero-inflated: when sampling transcripts in a single cell, the probability of a given gene not being detected is high, leading to large amounts of "dropouts" (false negative gene expression), necessitating more complex approaches. SCDE corrects for dropouts by taking into account aggregate expression levels across all cells to calculate dropout probabilities\sjcitep[.]{kharchenkoBayesianApproachSinglecell2014} These dropout probabilities are then used as priors to model gene expression levels in individual cells. Dropouts are weighted based on their prior probability, and likely relative (fold-change) gene expression levels are inferred. This approach ensures that highly-expressed genes are not penalized, and low-expressed genes are not inflated.

Directly visualising correlations or variance between many RNA-seq or microarray samples is difficult due to the high-dimensionality of this data. Traditionally, this was done by first reducing the dimensionality of the data using PCA, and then visualising the first 2 principal components in a 2D space. Alternatively, heatmaps with dendrograms were used to order correlated samples. The more fine-grained nature of cell states in single-cell data further introduces non-linearity, since gradients of expression in the population are no longer averaged out [I think this is important]. This non-linearity precluded the use of PCA. This problem was partially solved by the introduction of t-SNE, a technique first designed to visualise the MNIST dataset of handwritten digits\sjcitep[.]{maatenVisualizingHighDimensionalData2008} The earliest implementations of t-SNE were used for single-cell mass cytometry data\sjcitep[]{amirViSNEEnablesVisualization2013} (45 protein levels per cell), then single-cell qPCR\sjcitep[]{saadatpourCharacterizingHeterogeneityLeukemic2014} (175 genes) and later single-cell whole transcriptomics\sjcitep[]{macoskohighlyparallelgenomewide2015} (after PCA on \textasciitilde{\num{20000}}genes). t-SNE preserves local structure (close neighborhood of cells) at the cost of some concessions to global structure. Clusters of single cells can appear closer in the t-SNE embedding than they are in high-dimensional gene space. UMAP is a slightly newer dimensionality reduction algorithm which aims to better preserve global structure\sjcitep[.]{bechtDimensionalityReductionVisualizing2018} Some common criticisms of both t-SNE and UMAP is that they still distort global topologies\sjcitep[.]{chariSpeciousArtSinglecell2023} In addition, both methods are sensitive to hyperparameters (perplexity, number of neighbours) and stochasticity (e.g. initialisation). These tools are thus only used for exploration and quick visualisation of the data.

Simpson's paradox prohibits accurate investigation of gene expression dynamics in bulk samples. Single-cell datasets, however, can be both larger and much more fine-grained than bulk RNA-seq datasets sampled across different conditions or timepoints. \verb|Monocle| leverages this property inferring differentiation state from single-cell sequencing data sampled from differentiating cells\sjcitep[.]{trapnellDynamicsRegulatorsFate2014} High-dimensional gene expression space is reduced to statistically significant dimensions, and a minimum spanning tree is calculated between cells in this space. The longest path within this tree can then be used to calculate a "pseudotime" property. Beyond being able to order cells according to their differentiation state, genes can also be correlated with pseudotime to identify significant differentiation drivers.

By 2019, several single-cell sequencing technologies had emerged. Each had their own strengths and weaknesses, sometimes leading to technical artifacts in datasets even when assessing the same biological sample. Even the same technology used on different days could lead to batch effects due to sample degradation or other technical artifacts between experiments. This translates to cells clustering by dataset batch rather than biological state. In order to remedy this \verb|Seurat| aims to facilitate integration of multiple single-cell datasets across different technologies and conditions\sjcitep[.]{stuartcomprehensiveintegrationsinglecell2019} The package uses Canonical Correlation Analysis (CCA)\sjcitep[]{hotellingRelationsTwoSets1936} to calculate linear combinations of genes (canonical correlation vectors, in this case "metagenes") that capture common information between two datasets. Cells are then co-projected in this shared metagene space to create a new "joint embedding" where clustering and differential expression analysis can be performed. The canonical vectors can be used to re-transform differential metagenes back to the original gene set used. \verb|Seurat|'s CCA implementation could also be used for label transfer: if one dataset is labeled or annotated, proximity in the joint embedding space can be used to transfer labels from one dataset to another.

Whereas scRNA-seq is limited to counts in \textasciitilde{\num{22000}} genes (human, mouse), the accessible genome can span hundreds of thousands of open chromatin regions which can each be sampled a maximum of two times per cell. These effects lead to highly-dimensional, but sparse count matrices.

The relationship between open chromatin and cell phenotypes is even less clearly defined, potentially less linear than gene expression. A number of analysis tools have attempted to address these issues, using broadly two attempts:

Expression of protein-coding genes can be used as a rough proxy for a measurement of protein activity, which can be linked more directly to cell phenotype.

A scRNA-seq like approach where cells are first clustered, and differential chromatin accessibility is calculated between clusters. Latent semantic indexing (LSI), an approach borrowed from text analysis, can be used to perform this dimensionality reduction\sjcitep[.]{cusanovichsinglecellatlasvivo2018} Briefly, single-cell accessibility is first counted in annotated regions (usually accessibility peaks) or 5 kb genome bins, binarized, and scaled according to inverse document frequency (peaks that are not commonly accessible are weighted higher). Singular value decomposition (SVD), is then used to decompose the resulting weighted cell-accessibility matrix into latent features across cells:

\[
	M = U\Sigma V^T =
	\underset{(m \times n)}{\begin{bmatrix}
			\cdot  & \cdot  & \cdot  & \cdots & \cdot  \\
			\cdot  & \cdot  & \cdot  & \cdots & \cdot  \\
			\vdots & \vdots & \vdots & \ddots & \vdots \\
			\cdot  & \cdot  & \cdot  & \cdots & \cdot  \\
			\cdot  & \cdot  & \cdot  & \cdots & \cdot
		\end{bmatrix}}
	=
	\underset{(m \times r)}{\begin{bmatrix}
			\cdot  & \cdot  & \cdots & \cdot  \\
			\cdot  & \cdot  & \cdots & \cdot  \\
			\vdots & \vdots & \ddots & \vdots \\
			\cdot  & \cdot  & \cdots & \cdot  \\
			\cdot  & \cdot  & \cdots & \cdot
		\end{bmatrix}}
	\underset{(r \times r)}{\begin{bmatrix}
			\sigma_1 & 0        & \cdots & 0        \\
			0        & \sigma_2 & \cdots & 0        \\
			\vdots   & \vdots   & \ddots & \vdots   \\
			0        & 0        & \cdots & \sigma_r
		\end{bmatrix}}
	\underset{(r \times n)}{\begin{bmatrix}
			\cdot  & \cdot  & \cdot  & \cdots & \cdot  \\
			\cdot  & \cdot  & \cdot  & \cdots & \cdot  \\
			\vdots & \vdots & \vdots & \ddots & \vdots \\
			\cdot  & \cdot  & \cdot  & \cdots & \cdot
		\end{bmatrix}}
\]

Here, $m$ is the number of peaks, $n$ is the number of cells, and $r = \min(m,n)$ is the rank of the decomposition. U represents the peak-composition of the latent features, $\Sigma$ is diagonal and scales each latent feature, and V\textsuperscript{T} represents the contribution of each latent feature to each cell. Based on $\Sigma$, we can select the top n most important features and cluster cells in this reduced space using t-SNE. Differentially accessible regions (DARs) between clusters can then be calculated on the raw binary accessibility matrix using logistic regression, which is suited to model the odds of a binary event like chromatin accessibility.

Or, \verb|chromVAR|, which works in a fundamentally different way\sjcitep[.]{schepchromVAR2017} Instead of using hundreds of thousands of accessible peak regions, \verb|chromVAR| first groups these peaks into cistromes based on common TF motifs or pre-set functional annotations such as known enhancer peak sets. Accessibility within each cistrome is normalized and converted to z-scores, which are then used for t-SNE and clustering. Instead of known TF motifs, k-mers can also be used to identify novel motifs important in a given biological process.

In this work, \verb|cisTopic| was used extensively to generate and post-process scATAC-seq count matrices\sjcitep[.]{bravogonzalezblascistopic2019} Like \verb|chromVAR|, \verb|cisTopic| uses a probabilistic approach to model chromatin accessibility, but unlike \verb|chromVAR|, cisTopic uses LDA\sjcitep[]{bleiLatentDirichletAllocation2003}, calculates two sets of distributions: the region-topic distribution (regulatory regions grouped into "topics") and the topic-cell distribution (probability of a topic being associated with a cell) which should approximate the original data when multiplied.

\[
	\underset{m \times n}{
		\begin{bmatrix}
			x_{11} & x_{12} & \cdots & x_{1n} \\
			x_{21} & x_{22} & \cdots & x_{2n} \\
			\vdots & \vdots & \ddots & \vdots \\
			x_{m1} & x_{m2} & \cdots & x_{mn}
		\end{bmatrix}}
	\approx
	N \cdot
	\underset{m \times k}{
	\begin{bmatrix}
		p_{r_1t_1} & p_{r_1t_2} & \cdots & p_{r_1t_k} \\
		p_{r_2t_1} & p_{r_2t_2} & \cdots & p_{r_2t_k} \\
		\vdots     & \vdots     & \ddots & \vdots     \\
		p_{r_mt_1} & p_{r_mt_2} & \cdots & p_{r_mt_k}
	\end{bmatrix}_{}}
	\cdot
	\underset{k \times n}{
		\begin{bmatrix}
			p_{t_1c_1} & p_{t_1c_2} & \cdots & p_{t_1c_n} \\
			p_{t_2c_1} & p_{t_2c_2} & \cdots & p_{t_2c_n} \\
			\vdots     & \vdots     & \ddots & \vdots     \\
			p_{t_kc_1} & p_{t_kc_2} & \cdots & p_{t_kc_n}
		\end{bmatrix}}
\]

LDA parameters (probabilities) are estimated using a Markov chain monte carlo approach: regions are initially randomly assigned to topics, and topic-region assignment is then updated iteratively in each cell based on two factors: (1) the topic's occurrence in the cell and (2) the region's occurrence in each topic across all other cells. Instead of sampling in the entire [], sampling is only performed in [] (collapsed Gibbs sampling), which reduces total computational complexity compared to sampling in both region-topic and topic-cell distribution. This approach is more efficient than other Bayesian approaches (e.g. variational inference) due to the extreme sparsity of the data. tSNE or UMAP can then be used to visualise the resulting (normalized) topic-cell distributions.

Another advantage of LDA over LSI is that LDA's topics are interpretable, whereas LSI's latent features can be abstract\sjcitep[.]{steyversProbabilisticTopicModels2007} This property is exploited in \verb|cisTopic|, for example by extracting transcription factor binding motifs from the cis-regulatory topics found by LDA. The motif enrichment analysis itself is performed using \verb|cisTarget| [ref]. Regions and combinations of regions can also be annotated using nearest genes (ChIPseeker)\sjcitep[]{yu2015chipseeker}

\verb|cisTopic| also introduces a region score which rewards regions that are more specific to a topic, and penalises regions that are ubiquitous across topics:

\[
	\text{Region score} = \beta_{r,t} \left( \log \beta_{r,t} - \frac{1}{T} \sum_{t=1}^{T} \log \beta_{r,t} \right)
\]

Consider Shannon entropy $H(X) = -\sum_{i} p(x_i) \log p(x_i)$, then the term \(\beta_{r,t} \log \beta_{r,t}\) can be considered the local information content of the region in topic context, while the term \(\frac{\beta_{r,t}}{T} \sum_{t=1}^{T} \log \beta_{r,t}\) is the average log-probability of the region acrosss all topics [double check this, is beta a probability?]. The region score is thus an average-normalized measure of a given region's information content, indicating how specific it is to each topic. Topics can then be scored for TF motif enrichment by counting TF motif occurrence in the score-ranked regions and calculating the area under this rank curve (AUCell\sjcitep[]{aibarscenicsinglecell2017}).

\verb|cisTopic|'s LDA approach was benchmarked against other popular tools such as \verb|chromVAR|, \verb|scABC|, \verb|BROCKMAN|, \verb|SCRAT|, \verb|Cicero|, and LSI, using both simulated single-cell ATAC-seq datasets and real data from FAC-sorted hematopoietic cells. \verb|cisTopic| typically yielded higher scores for cell-type clustering, especially in low-coverage scenarios, confirming that the method can more robustly capture biologically meaningful patterns in sparse single-cell ATAC-seq data.

\section{Foundation and task-specific models}
In 1959, Hubel and Wiesel showed that specific neurons in a cat's visual cortex respond to common spatial patterns (e.g. edges, corners, orientations) in specific locations within the cat's visual field\sjcitep[.]{hubel1959receptive} These patterns can overlap when layers of neurons pass information onwards, forming broader structures which ultimately allow the cat to recognise complex objects. This idea was borrowed to implement convolutional neural networks (CNNs) for handwritten digit recognition\sjcitep[.]{fukushima1980neocognitron,lecun1998gradient} Rasterized (vectorized) images are scanned by a "filter", converting the original data into a new representation. This new representation is then passed on to the next layer, where it is again scanned by a new filter, and so on until the final layer. CNNs are thus well suited for detecting spatial patterns, and integrating these patterns into larger, more global structures.

CNNs have been successfully used in earlier enhancer prediction models, such as DeepBind and DeepSEA, validating their use in genomics. An early example was DeepSEA\sjcitep[,]{zhou2015predicting} a CNN trained on ENCODE and Roadmap Epigenomics data (690 TF ChIP-seq + 125 DHS + 104 H3K27Ac/H3K4Me3 datasets). This model could simultaneously predict these 919 chromatin features at 1 base resolution with higher accuracy than previous tools (\verb|CADD|, \verb|GWAVA|). Saturation mutagenesis analyses showed that DeepSEA could de novo predict known allelic imbalances and eQTLs (using chromatin features as a proxy).

Meta's Evolutionary Scale Modeling (ESM) applies large language model architecture (specifically, BERT) to protein language to predict masked tokens in amino acid sequences. The log-likelihood of proposed sequences serves as an estimate for how disruptive given mutations will be, allowing researchers to triage synthetic designs. Between 2021 and 2025, ESM grew from 650M\sjcitep[]{rives2021biological} to 15B\sjcitep[]{lin2023evolutionary} and recently 98B\sjcitep[]{hayes2025simulating} parameters. ESM-3 was trained on 771B tokens across 2.78B proteins, amended with synthetic data generated by AlphaFold, and trained over \SI{1.07e24}{\flops} of compute. ESM-3 also introduced multimodal masked token modeling: joint tokenized amino-acid sequence, atomic structure, and region annotations can be passed partially masked, and the model will jointly reconstruct missing tokens. This led to the generation of esmGFP, a completely synthetically designed fluorescent protein.

AlphaFold 1 was a CNN trained on protein structures (PDB) and multiple sequence alignments (MSAs) to predict residue-residue distances\sjcitep[.]{senior2020improved} AlphaFold 2 switched architecture, passing MSAs through Evoformer, a model with transformer-based self-attention, to predict spatial contacts and ultimately complete 3D protein structure\sjcitep[.]{jumper2021highly} These changes led it to achieve a median backbone accuracy of \SI{0.96}{\angstrom} in CASP14 - surpassing the next best method by \textasciitilde\SI{2}{\angstrom}. AlphaFold 3 included a generative diffusion model to handle atomic coordinates directly rather than relying on MSAs. As a result, the model is capable of predicting binding interactions across protein, DNA/RNA, and small molecules, and performs better than AlphaFold 2 on other tasks. DeepMind has not released the precise training data used for AlphaFold 1-3, but it is generally thought that the jumps in size were not as large as for GPT and ESM: AlphaFold 1 was already trained on a large fraction of available PDB and MSA data, and AlphaFold 3's weights are only \SI{1}{\giga\byte} in size. When data constrained, model architecture innovations such as end-to-end modeling, introduction of attention and diffusion, are thus still viable paths to raw performance improvement. However, recent benchmarks have also shown that protein/ligand binding models, including AlphaFold 3, suffer performance drops when re-trained without train-test leakage\sjcitep[.]{plinder2024proteinligand} Ligands that are sparsely represented in the training data were especially problematic, suggesting that \textit{"data scarcity remains a major challenge for these methods"}\sjcitep[.]{skrinar2025proteinligand} Optimistically, these findings suggests that generation of additional or higher-quality data will yield further performance improvements in the space.

In a similar vein, several foundation models have been developed in the field of genomics. The original DNABERT was an 86M parameter transformer trained on the 3.2 Gbp human reference genome to classify promoters, TF-binding sites, and other regulatory features\sjcitep[.]{ji2021dnabert} The model was competitive with ClinVar for SNV scoring, but had a relatively small context window of 512 bp, so could not compete in long range tasks such as enhancer-promoter pairing. Nucleotide Transformer (NT) extended the BERT approach to multi-species data: adding both genomic and evolutionary variety by using \num{3300} individual human genomes and 850 other organisms, totaling 262B tokens. NT consistently outperformed BERT and DeepSEA on promoter, enhancer, chromatin, and histone mark prediction, and enabled zero-shot scoring of SNPs and indels - achieving better accuracy than previous models on ClinVar benchmarks\sjcitep[.]{dallatorre2025nucleotide} Interestingly, several training sizes and regimes were investigated. Training on many species improved performance on human benchmarks more than increasing parameters from 500M to 2.5B, suggesting that diversity matters more than raw volume. Compute also partially offset size: smaller NT models trained for longer approach the accuracy of larger ones. Recently, Evolutionary Scale Modeling for Genomes (Evo 2) pushed this scaling further with a 40B-parameter model trained on 9.3T tokens spanning all domains of life\sjcitep[.]{brixi2025genome} The model scores variant effects across taxa, and supports up to 1 million tokens of context, enabling the generation of entire synthetic mitochondrial or bacterial genomes. Loss decreased smoothly with more data and parameters, with no saturation observed so far. However, a 7B checkpoint already matched the 40B model on most clinical-genomics benchmarks, suggesting diminishing returns beyond this size for short-range tasks. Instead, data engineering, such as biasing the training distribution toward gene-proximal regions and de-emphasizing repetitive DNA, improved AUROC by up to 0.1, even at constant parameter count. Larger models mainly unlocked generative capabilities: only the 40B Evo 2 model could synthesize coherent genome-scale DNA.

Several track-predicting models have been released. In 2018 with Basenji2, a CNN trained on \num{4229} human epigenomic (DNase-seq, histone-ChIP) and transcriptional (CAGE) tracks across > 500 cell and tissue types. With a large receptive field of 131 kb\sjcitep[]{kelley2018sequential}, the model could predict 128-bp binned coverage across the genome: users feed any 131-kb reference or mutant sequence to the pretrained model (or fine-tune on new tracks) and obtain coverage predictions for each of the \num{4229} tissue-specific tracks it was trained on. In 2021, Enformer replaced dilated convolutions with global self-attention and pushed the receptive field to 100 kb with a 200 kb input window\sjcitep[.]{avsec2021effective} Trained now on \num{5313} human and \num{1643} mouse tracks (TF and histone-mark ChIP, DNaseI, ATAC and CAGE), it predicts these tracks at 128 bp resolution, including long-range interactions. Borzoi is another CNN-attention hybrid, trained on thousands of CAGE, DNase, ATAC, and ChIP-seq datasets similarly to Basenji2 and Enformer, but also adding 866 human and 279 mouse RNA-seq tracks\sjcitep[.]{linder2025predicting} The model predicts these tracks now at 32 bp-resolution. Kundaje lab introduced ChromBPNet, a CNN trained on ENCODE ATAC-seq and DNase-seq tracks for the five tier 1 ENCODE cell lines (GM12878, HepG2, K562, IMR90, H1-hESC)\sjcitep[.]{pampari2025} A smaller sub-net learned each enzyme's sequence biases based on non-peak regions signal, allowing ChromBPNet to isolate each motif's true footprint independent from assay used. This allows the model to predict, at single base resolution, the accessibility read profile (shape + total counts) that either ATAC-seq or DNase-seq would produce.

Geneformer applies the transformer playbook to a collection of 30M human scRNA-seq cells across various tissues, with cells tokenized as a ranked list of their top 2048 genes sorted by expression (no count information)\sjcitep[.]{theodoris2023transferlearning} A transformer architecture is then trained to fill in masked gene positions, implicitly learning patterns of co-expression and regulation across tissues and conditions present in the data. The model is designed to fine-tuned for specific tasks such as dosage-sensitivity classification, regulatory range prediction, and chromatin-state inference. scFoundation, another masked-prediction transformer, was trained on 100M single cells\sjcitep[.]{hao2024large} Varying size from 3M to 100M parameters showed that its loss curves followed the same token vs FLOPs power laws seen in language models.

Recent work has shown that single-cell chromatin atlases can be mined directly to learn enhancer grammar and design new regulatory elements. % --- contrast to foundation models

scRNA-seq of nine patient-derived cultures uncovered an intermediate state that co-expresses melanocytic factors (SOX10, MITF) and mesenchymal regulators (SOX6, EGR3).\sjcitep[]{wouters2020robust} Follow-up bulk ATAC-seq at four time points after SOX10 knock-down showed gradual chromatin shifts rather than abrupt switches. Expanding to 26 melanoma samples from six species, Minnoye et al.\sjcitep[]{minnoye2020cross} found SOX10/MITF/TFAP2A-rich enhancers in melanocytic cells and AP-1/TEAD motifs in mesenchymal cells, with motif usage conserved in dog, horse, pig and zebrafish. The DeepMEL model - a DanQ CNN-RNN trained on \num{339099} human ATAC peaks - predicted state-specific enhancer activity from sequence alone and guided the synthesis of new MES and MEL enhancers.

A similar approach clarified \textit{Drosophila} brain development. Janssens et al.\sjcitep[]{janssens2022decoding} profiled \num{240919} scATAC-seq nuclei from the developing \textit{Drosophila} brain across nine time points. Peaks were clustered with cisTopic to obtain topic sets of co-accessible, cell-type-specific regions. A CNN was trained to predict each topic's aggregated accessibility from 2 kb of sequence. SHAP DeepExplainer scores highlighted the nucleotides most responsible for each prediction, revealing, for example, that \textit{eyeless} and \textit{mef2} motifs act synergistically when placed in close proximity, whereas repressor motifs can override activators. In-silico saturation mutagenesis confirmed the minimal length of active enhancers (as short as 49 bp), and reporter studies showed that 41 of 63 synthesized candidates drove the expected cell-type expression in transgenic flies.

Building on these ideas, the \verb|CREsted| pipeline trains compact CNNs (e.g.\ DeepBICCN2, 6M parameters) directly on scATAC-seq peaks, interprets motif logic and performs de novo enhancer design. Starting from topic-assigned peaks or pseudobulk heights, models are first pretrained on the full peak set and then fine-tuned for cell-type specificity. In mouse motor cortex, \verb|CREsted| reached Pearson r \textasciitilde 0.82 on held-out peaks and retrieved the motifs underlying 171 in-vivo-validated enhancers. A human PBMC version recovered every known TF footprint at the CD79A and TCR\textalpha enhancers and captured 34\% more informative bases than Borzoi. DeepZebrafish, trained on \num{793273} peaks across \num{639} zebrafish cell-type/time-point combinations, served as an oracle for greedy in-silico evolution: five of seven 2-kb designs drove reporter expression specifically in cardiac muscle, somatic muscle or endothelial cells at 48 hpf.

These domain-focused models complement large foundation models such as Basenji2, Enformer and scFoundation: they require far less compute, yet excel at highly specific questions like cell-type enhancer logic. The common thread is clear - rich public datasets (ENCODE, CellxGene, Human Cell Atlas, Tahoe-100 M) plus transparent model-interpretation tools are accelerating iterative cycles of measure, model, design.

One modality is palpably absent from the analysis in this chapter: perturbation effect predictions - either chemical or genetic. Of course, almost all models discussed predict variant effects, but they are trained on observational, evolutionary data. Few large, high-quality perturbation datasets exist so far - especially when compared to the total space, which is also extremely combinatorial for both genetic and chemical perturbations. In order to predict all downstream effects of a given mutation, true perturbation data will be needed at scale. Extreme throughput arrayed perturbation remains an open technical challenge.
