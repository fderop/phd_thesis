\addcontentsline{toc}{chapter}{\protect\numberline{}Preface}

% The work described in this thesis encompasses two parts. First, we developed an open-source droplet microfluidic platform for scATAC-seq and scRNA-seq, and second, we performed a systematic benchmark of scATAC-seq methods. Together, these efforts touched on all low-level aspects of omics data generation: we optimized reaction chemistries, engineered hardware, wrote software, managed large data structures, and coordinated high-power compute. The end result is (a) HyDrop, an open-source droplet-microfluidic single-cell assay that is competitive with commercial solutions (\autoref{ch:design_development}), and (b) \verb|PUMATAC|, a benchmarking framework for high-throughput single-cell ATAC-seq datasets (\autoref{ch:benchmarking}).
