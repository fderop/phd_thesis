# PhD Thesis

[Read the thesis PDF](https://github.com/fderop/phd_thesis/blob/main/phd_thesis.pdf).

`./compile.sh` compiles the thesis.

### Paper PDFs

* `papers/elife-73971-v5.pdf` is the eLife HyDrop paper.
* `papers/s41587-023-01881-x.pdf` is the Nature Biotechnology benchmark paper.

If `papers/elife-73971-v5-thesis-corrected.pdf` is available, the build uses it instead of the original HyDrop PDF.

If either paper is missing, the script shows a warning and asks whether to continue.
